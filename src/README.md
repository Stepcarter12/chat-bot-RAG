# src

Chứa toàn bộ **mã nguồn sản phẩm** — điểm trung tâm duy nhất cho code.

## Nội dung điển hình

- `backend/` — API server, business logic
- `frontend/` — Giao diện người dùng
- `shared/` — Thư viện và module dùng chung

## Dành cho AI Agent

Mọi code sản phẩm đều nằm ở đây — agent không cần đoán mò vị trí file, giảm thiểu sai sót và tăng tốc độ làm việc.

# ops

Chứa toàn bộ **công cụ và hạ tầng** — mọi thứ không phải là mã sản phẩm trực tiếp.

## Nội dung điển hình

- Cấu hình Docker / Docker Compose
- Kubernetes Helm Charts
- Script triển khai và tự động hóa
- Cấu hình CI/CD
- Script tiện ích (utilities)

## Dành cho AI Agent

Tách biệt hạ tầng khỏi logic nghiệp vụ giúp AI Agent không nhầm lẫn giữa "deploy tooling" và "product code" — agent biết chính xác nơi tìm cấu hình vận hành.

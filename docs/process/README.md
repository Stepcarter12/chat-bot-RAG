# docs/process

Chứa nội dung **động** phản ánh quá trình phát triển — những tài liệu thay đổi thường xuyên theo tiến độ dự án.

## Nội dung điển hình

- Quyết định kỹ thuật đã đưa ra (ADR - Architecture Decision Records)
- Ghi chú cuộc họp (meeting notes)
- Kế hoạch triển khai (deployment plans)
- Nhật ký thay đổi (changelogs)

## Dành cho AI Agent

AI Agent đọc thư mục này để hiểu **ngữ cảnh hiện tại** của dự án — quyết định nào đã được đưa ra, lý do tại sao, và hướng đi tiếp theo là gì.

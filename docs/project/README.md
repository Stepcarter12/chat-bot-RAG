# docs/project

Chứa kiến thức **tĩnh** về sản phẩm — những tài liệu ít thay đổi theo thời gian.

## Nội dung điển hình

- Kiến trúc hệ thống (system architecture)
- Sơ đồ thực thể quan hệ (ERD)
- Đặc tả tính năng (feature specs)
- Yêu cầu kỹ thuật (technical requirements)

## Dành cho AI Agent

AI Agent đọc thư mục này để hiểu **cái gì** đang được xây dựng và **tại sao** — giúp agent đưa ra quyết định chính xác hơn mà không cần hỏi lại.
